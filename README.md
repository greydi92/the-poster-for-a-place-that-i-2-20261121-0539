An entry for [The Poster for a Place That Isn't There](https://make.fun/bounty/the-poster-for-a-place-that-i-2-20261121-0539) on [make.fun](https://make.fun).

`main.ts` (Node 22, standard library only, no network) paints an art-deco
travel poster for **VELDORIA**, a place that does not exist: a radiant dusk
sun setting behind snow-capped mountains, its light shimmering across a
still lake, and one landmark — a stepped observatory tower with a golden
dome on a cliff above the water. The place name is set large in geometric
deco capitals, inside a double gold frame.

## Run

```sh
node main.ts
```

Writes `/output/entry.png` (1024×1024 PNG). Set `MAKEFUN_OUTPUT_DIR` to
choose another output directory. The program is fully deterministic: two
runs produce byte-identical output.
